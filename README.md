# 纸上的小人

零依赖纯前端的程序化手绘项目（复刻 avatar-presse）：黑白线条、墨色浓淡、纸张质感全部由 canvas 代码画出——没有图片、没有框架、没有构建。

在线预览：https://selenave-d.github.io/face/

| 页面 | 玩法 |
| --- | --- |
| index.html | 单人展示：随机一个手绘小人，可站立 / 挥手 / 走路 / 跳跃 / 跳舞 |
| heads.html | 一墙脸：手绘头像墙，点一颗放大细看 |
| photo.html | 班级合影：两排 10 人点选 5 个拍合影，按共享特征凑牌型计分，拍完二选一收道具 |
| crowd.html | 一群朋友：底部滑块从 1 拉到 500 人，拉满全员起跳放烟花 |

桌面与手机均可；双击任一 HTML 离线即开。维护文档见 [docs/](docs/)。
